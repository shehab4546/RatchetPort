# RatchetPort V2.0 — Stellar Update

A clearer image, a more flexible control setup, and independent language choices.
V2.0 brings the 1440p/4K black-world correction together with memory improvements,
dynamic button prompts and a redesigned control editor.

## Fixed and delivered

- **The world renders again at 1440p and 4K.** Corrected the high-resolution resource-allocation path that left the 3D world black while menus and the HUD remained visible. Gameplay verification confirmed the fix at both resolutions. [#19](https://github.com/shehab4546/RatchetPort/issues/19)
- **Your selected game language stays selected.** Launching from RatchetPort preserves supported saved languages, including Latin American Spanish, instead of resetting them to English. [#14](https://github.com/shehab4546/RatchetPort/issues/14)
- **Game languages are selectable in the launcher.** Text/subtitles and voice have separate selectors; the launcher interface language remains independent. This delivers the language-selection request in [#5](https://github.com/shehab4546/RatchetPort/issues/5). Silent non-English gameplay dialogue remains tracked separately in [#31](https://github.com/shehab4546/RatchetPort/issues/31).
- **Higher resolution and frame-rate options are available.** Choose Original, 720p, 900p, 1080p, 1440p or 4K internal resolution, with Original/30 FPS or experimental 60 FPS timing. These address [#8](https://github.com/shehab4546/RatchetPort/issues/8) and [#27](https://github.com/shehab4546/RatchetPort/issues/27). Higher frame-rate modes are not included.
- **Original PlayStation artwork is recognized correctly.** Corrected the source texture identities that could reject restored game files with a prompt-identity mismatch.
- **Save and Play remain accessible.** Long status text no longer takes over the footer space.

## Controls and dynamic prompts

- Separate **Primary and Secondary** bindings for each keyboard/mouse action.
- One selector per stick: **WASD, Arrow keys, Mouse movement or None**.
- Duplicate inputs are rejected immediately across Primary, Secondary and both sticks. The conflict message identifies the existing assignment; no binding is silently moved. Save and launch retain a final validation.
- Diagonal movement combines both axes. Mouse movement preserves its direction and releases the emulated stick when movement stops.
- Digital triggers stay held until release, and controller analog trigger pressure is preserved. Grenade behavior still needs scene-specific gameplay testing.
- Keyboard, mouse and Xbox prompts follow the saved mappings, including standalone camera-stick and Cross tutorial prompts. Secondary bindings supply the icon when Primary is unbound.
- Choose **Original / PlayStation, Xbox, Keyboard & mouse, or Auto at launch**. Auto selects a style at startup; it does not switch with the last device used during gameplay.

## Memory and rendering improvements

- **Adaptive texture-cache cleanup** follows the driver's memory budget and spreads work across bounded sweeps while retaining the selected resolution.
- **More room for high-resolution resources:** 1440p and 4K receive larger native graphics heaps and matching direct-memory reservations. This corrects the allocation path behind the tested black-world issue.
- **Safer deferred rendering commands:** copied command data remains alive across recording-chunk rollover, fixing a use-after-free path in large batches.
- **Clearer allocation diagnostics** help identify memory pressure and failed rendering resources.

The larger high-resolution reservations add approximately **384 MiB at 1440p**
and **768 MiB at 4K** to startup commit. They improve allocation headroom, not
reduce every device's RAM use. Performance and available memory still determine
which preset fits a device; no universal FPS increase is claimed.

## Graphics, audio and languages

**Low, Medium, High, Very High and Ultra** presets coordinate internal/output
resolution, shadow-map limits, anisotropic filtering and motion blur. Manual
changes produce a Custom setup. Shadow caps include **1024, 512 and 256 px**.

Audio recovery discards excessive stale queued sound after a stall, with clearer
diagnostics for starvation and backlog. This is separate from missing voice data.

The supported CUSA01047 USA v1.00 language choices are:

| Choice | Text / subtitles | Voice data |
| --- | --- | --- |
| English | American English | American English |
| French | French | French |
| Portuguese (Portugal) | European Portuguese | European Portuguese |
| Portuguese (Brazil) | Brazilian Portuguese | Brazilian Portuguese |
| Spanish (Latin America) | Latin American Spanish | Mexican Spanish |

### If a voice language is silent

Select the game folder and voice language in **Game and saves**, then wait for the
launcher's **Voice archive** check to finish. It shows the expected archive and
checks whether it is missing, empty or contains obvious repeated-block damage.
The launch log also includes the selected locale and the check result.

A warning or failure means the archive needs investigation; restore damaged or
missing data from your own original game dump. **OK means the sampled checks
passed, not that every audio asset or dialogue line was verified.** If the archive
passes but gameplay dialogue remains silent, the issue is still tracked in
[#31](https://github.com/shehab4546/RatchetPort/issues/31), with earlier reports in
[#5](https://github.com/shehab4546/RatchetPort/issues/5). English voice can be
selected independently of text/subtitles. Save and restart after changing game
languages. Cinematic and gameplay voice behavior can differ.

## Launcher additions

- **Check for updates** finds newer stable releases. Automatic installation verifies the Windows package's SHA-256 digest and checks archive paths.
- **Optional diagnostic reports** include hardware information and filtered technical log excerpts. Upload is off by default, with bounded report size and delivery frequency.
- **Consistent V2.0 identity** in the launcher, executable properties, build metadata and download names.

## Compatibility and remaining reports

Requires **CUSA01047 USA v1.00** and your own game files. Other regions and game
updates are not added by this release. Mouse camera control remains analog-stick
emulation with the game's turn-speed limit.

The 1440p/4K black-world fix does not establish a fix for every graphics problem.
The distinct reports for unchanged resolution ([#21](https://github.com/shehab4546/RatchetPort/issues/21)),
RX 570 startup crashes ([#24](https://github.com/shehab4546/RatchetPort/issues/24)),
character flicker ([#25](https://github.com/shehab4546/RatchetPort/issues/25)) and
the Plasma Striker/overlay shortcut conflict ([#29](https://github.com/shehab4546/RatchetPort/issues/29))
remain open. The project remains experimental; long-session and broad hardware
compatibility are not established by a successful build.
