# V1.5 — Visual Controls Preview

More control over the look of **Ratchet & Clank on PC**. V1.5 brings dedicated
motion-blur and shadow-detail options to the launcher, alongside the existing
experimental 60 FPS mode.

## New visual controls

### Motion blur

Keep the game's original motion blur or turn it off. A single setting controls
the general effect, making it easier to choose the presentation you prefer.

### Shadow detail

Choose from four shadow-map settings:

| Setting | Shadow-map resolution |
| --- | --- |
| **Original** | The game's original settings |
| **1024 px** | Up to 1024 × 1024 per map |
| **512 px** | Up to 512 × 512 per map |
| **256 px** | Up to 256 × 256 per map |

Lower caps reduce shadow detail. Each value is a maximum; individual shadows
may already use a smaller map. Coverage of separate sun shadows remains unverified.

### Direct access in the launcher

Both controls are available on **Home** and **Graphics**, with Original as the
default. Changes take effect after restarting the game.

## Settings improvements

- Motion-blur and shadow preferences remain saved when using the in-game menu.
- The in-game Graphics information panel shows the effects selected for the
  current launch.
- Either effect can return to Original independently, while keeping the other
  graphics preferences.

## Frame-rate options

**30 FPS / Original** and **60 FPS (experimental)** remain available. The new
visual settings can be used with either mode.
