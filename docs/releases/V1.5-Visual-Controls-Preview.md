# V1.5 — Visual Controls Preview

Home and Graphics now offer **Motion blur: On / Original or Off**, and
**Shadow-map resolution: Original, 1024, 512 or 256 px maximum**. Changes apply
when the game starts again. Both controls default to Original and preserve the
saved selection when settings are saved from the in-game overlay.

Blur Off follows the game's general blur-strength disable path. Shadow options
cap the reviewed manager's map sizes while keeping its atlas and tile metadata
consistent. Smaller caps reduce detail; maps may already be smaller, and coverage
of separate sun shadows is unverified. The fixed atlas allocation is unchanged.

The title, executable metadata and archives identify **V1.5 — Visual Controls
Preview**. The previous experimental 60 FPS option remains available independently.
All patches require the fingerprinted CUSA01047 USA 01.00 source. Rejected groups
fall back to Original; native transaction failure aborts before guest execution.
Selecting Original and restarting removes the corresponding patch.

Isolated native checks passed 32 blur-gate cases, 20 strength-consumer cases and
312 shadow allocation cases. All 16 option combinations passed profile checks.
These are not gameplay or GPU-rendering results. Windows build/package validation
is tracked by CI; release publication must use a successfully tested build.

To compare: keep the same scene/save, change one setting, save and restart.
Try 1024 first, then 512/256; inspect shadow detail and flicker. Compare blur with
camera movement and moving objects at 30 and 60 FPS. Restore Original and restart
to verify reversal. Keep the run log and patch status for each comparison.
See [implementation evidence and acceptance steps](../RP05_VISUAL_CONTROLS.md).

Internal-resolution patches and 120 FPS are not enabled. No new gameplay,
tearing, cutscene-stutter or performance result is claimed.
