# RatchetPort V1 — Pre-Alpha

First public experimental Windows x64 release for **Ratchet & Clank PS4,
CUSA01047 USA v1.00**. **V1 is not a stable 1.0 or a guarantee of playable gameplay.**

## Your own disc and dump are required

You must own the original PS4 game disc and make your own dump from that disc
using your own PS4. No game files, PS4 proprietary modules, keys, prepared game
images or game artwork are included. Do not use or share someone else's dump.

يجب امتلاك قرص اللعبة الأصلي وعمل dump بنفسك من قرصك باستخدام جهاز PS4 الخاص بك.
لا توجد ملفات لعبة أو نظام PS4 أو مفاتيح ضمن الإصدار، ولا يوفر المشروع تنزيل اللعبة.

## Included

- RatchetPort launcher targeting CUSA01047 USA v1.00, with original app icons.
- Direct-play helper, native runtime and GPU capability tool.
- Ratchet scheduler, dispatch batching, record overflow and scissor corrections
  retained from local bring-up work.
- Removal of God of War III hooks, cheats, patches and product assets.
- Conservative defaults: 30 FPS cap, VSync on, 720p output, zero-clear off,
  linear readbacks on and deferred GPU readbacks off. No Ratchet binary patches.
- LGPL FFmpeg shared libraries built without GPL/version3/nonfree options,
  dependency notices and corresponding source attachments.

## Tested and still broken

Tested locally on **Windows 11 Pro build 26300, Intel Core i5-12400, Intel UHD
Graphics 730 driver 32.0.101.7088, 12 GB RAM**. Title/menu/difficulty selection
were reached; the tester confirmed loading and the opening movie with deferred
readbacks disabled. A freeze was reported during an attempted skip after several
unidentified button presses. Actual playable movement, audio, physical controller,
save/load, 1080p and long sessions remain unverified. These observations predate
the final LGPL FFmpeg packaging change; final V1 gameplay has not been revalidated.

`VK_ERROR_DEVICE_LOST` on UHD 730 remains unresolved. Windows memory allocation
error 1450 has also occurred before gameplay. A 30 FPS setting is not evidence of
sustained 30 FPS performance. See [TESTING.md](../TESTING.md) for separate automated
results, skips and the limits of the game observations.

## Files and source

- `RatchetPort-Windows-PreAlpha.zip`: extract completely, then open `RatchetPort.exe`.
- `RatchetPort-V1-Source.zip`: the release commit plus pinned submodule sources
  and tracked patches; build instructions included.
- `ffmpeg-9.0.2.tar.xz`: exact unmodified FFmpeg sources used for the bundled DLLs;
  build recipe: `packaging/windows/build-ffmpeg.sh` in the source archive.
- `SHA256SUMS.txt`: checksums for those assets.
