# RatchetPort V1.3 — Verified Preview

V1.3 shipped the new patch framework, but the frozen launcher still displayed
`1.0.0-prealpha` and `build-info.json` still named V1.1 PlayGo. Renaming the GitHub
release and download files did not update those internal labels.

This correction uses `scripts/release_info.py` as the common identity for the
launcher title, home-page version, sidebar and Advanced version labels, Windows
executable version resource, packaged README, build metadata and archive names.
The home page states what this preview provides and which feature patches remain
disabled. The overall launcher layout is unchanged.

The Windows package smoke test now checks the frozen release metadata, executable
version resource and actual launcher window title against `build-info.json`.

This retains the verified patch transactions from V1.3: exact source/ELF hashes,
unique signatures, original-byte and segment checks, conflict prevention,
whole-group rejection and loader receipts. Original game files are not modified.
It does not enable FPS, motion-blur or internal-resolution patches and does not
claim a new tearing or cutscene-stutter fix. See [patch documentation](../PATCHES.md).

Extract to a new folder. The title bar must show
`RatchetPort V1.3 — Verified Preview`, the home page must show `RatchetPort V1.3`,
and the sidebar/Advanced version must be `v1.3`. Use the supported CUSA01047 USA
01.00 dump and baseline settings. Verify startup and save/load on your machine;
prior automated/hardware results are not a guarantee of gameplay on this build.
