# Experimental file overlays

The inherited generic file-overlay utilities remain available for development. Their path traversal, case handling, conflict detection and original-file preservation are tested using synthetic files. This does not establish compatibility with Ratchet's content formats.

No Ratchet mod or game asset is included. Keep file overlays disabled for baseline validation. Do not use another game's WAD replacements or binary patches. The launcher prepares disposable views instead of modifying the original dump; prepared executable files and game-derived outputs must remain local. Binary patch selections are disabled for CUSA01047 until independently verified patches exist.
