Ratchet & Clank (2016)PC port project.

RatchetPort is an experimental native Windows runtime for the PS4 game. Follow its progress, review what has been tested, and try the public Pre-Alpha with your own disc dump.

Pre-Alpha: stable gameplay is not established. Loading and the opening movie were reached, but freezing and GPU Device Lost remain unresolved.

You must own the original PS4 disc and make your own dump from that disc using your own PS4. This download contains the runtime, not the game. No proprietary PS4 modules, keys or game artwork are distributed.

What actually works so far?

Observed in earlier testing

Menus & opening movie

The title screen, main menu and difficulty selection were reached. The tester confirmed loading and the opening movie with deferred GPU readbacks off.

Still unresolved

Gameplay stability

A freeze occurred during an attempted movie skip after several button presses. Playable movement, reliable skipping, audio, physical controllers and save/load remain unverified.

Automated checks passed

Build & packaging

46 native tests passed. Python: 399 passed, 51 skipped, no failures. The extracted Windows package passed a startup smoke test. These checks do not certify gameplay.

Game observations predate the final LGPL FFmpeg packaging change. Full gameplay on the final V1 package has not been revalidated.

Try RatchetPort on Windows

  1. Make a dump from your own original CUSA01047 USA v1.00 PS4 disc using your own PS4.
  2. Download and extract RatchetPort-Windows-PreAlpha.zip completely.
  3. Open RatchetPort.exe, select your dump folder and save the settings.
  4. Start with the defaults: 720p output, 30 FPS cap, VSync on and deferred readbacks off.

Windows x64, an AVX-capable CPU and Vulkan 1.3 graphics are required. Leave enough memory and Windows commit capacity for the guest pool and renderer.

Controls & reporting

Keyboard mappings use PS4 buttons: Space = Cross, Left Shift = Circle, E = Square, Q = Triangle, and Enter = Options. WASD maps to the left stick.

If a test fails, report your CPU, GPU, driver, RAM and exact steps. Review logs for personal information before sharing. Never upload your game dump, proprietary modules or prepared game files.

About this Ratchet & Clank PC port

Which Ratchet & Clank game does this target?

The 2016 PS4 game, CUSA01047 USA version 1.00. This project does not target Ratchet & Clank: Rift Apart or the original PS2 game.

Is this an official PC release?

No. RatchetPort is an unofficial community project, unaffiliated with Sony or Insomniac Games. It is based directly on SpartanPort and uses renderer and shader-recompiler work from shadPS4.

Does the download include the game?

No. You must own the original disc and make your own dump using your own PS4. The project provides no game downloads, proprietary modules, keys or game artwork. Do not use or share someone else's dump.

Is V1 stable or fully playable?

No. V1 is a Pre-Alpha milestone. Freezing, Device Lost and memory failures are documented; successful automated tests do not establish stable gameplay.

Where are the source and licenses?

The V1 release includes RatchetPort sources with pinned submodules, the exact FFmpeg source archive and checksums. The project preserves GPL-2.0 and applicable per-file licenses; its bundled FFmpeg build uses LGPL-2.1-or-later. See credits and distribution notices.
